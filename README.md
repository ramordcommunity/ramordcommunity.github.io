## About

**Ramord Community** develops modern, lightweight, modular open-source software and tools designed for Linux, Windows, and interconnected computing environments.

Visit our official web portal: **[ramordcommunity.github.io](https://ramordcommunity.github.io)**

---

## Ecosystem

### 1. [Ramord Link](https://github.com/ramordcommunity/ramordlink)
- **Description:** Network, KVM mouse/keyboard sharing, and local file sharing bridge between Linux and secondary computers (Windows/Mac).
- **Protocols & Integrations:** NetworkManager shared gateway, Deskflow KVM, lightweight HTTP transfer, Samba (SMB).
- **Languages:** 6 native languages (TR, EN, DE, ES, FR, IT).

### 2. [Ramord Cast](https://github.com/ramordcommunity/ramordcast)
- **Description:** Low-latency wireless screen mirroring and independent virtual second-display tool for Smart TVs and external monitors on Linux.
- **Protocols & Integrations:** Apple AirPlay 2, Samsung Workspace (RDP 2nd Screen), Google Cast.
- **Languages:** 6 native languages (TR, EN, DE, ES, FR, IT).

## Türkçe Açıklama

**Ramord Topluluğu**, Linux, Windows ve birbiriyle bağlantılı çalışma ortamları için modern, hafif ve modüler açık kaynaklı masaüstü araçları geliştirmektedir.

Resmi web portalımızı ziyaret edebilirsiniz: **[ramordcommunity.github.io](https://ramordcommunity.github.io)**

### Projelerimiz

1. **[Ramord Link](https://github.com/ramordcommunity/ramordlink):**
   - Linux ve ikincil bilgisayar (Windows/Mac) arasında internet paylaşımı, fare ve klavye (KVM) paylaşımı, ortak pano senkronizasyonu ve yerel dosya transfer köprüsü.

2. **[Ramord Cast](https://github.com/ramordcommunity/ramordcast):**
   - Linux masaüstünüzü Smart TV ve monitörlere kablosuz yansıtma ve bağımsız sanal ikinci ekran oluşturma aracı (Apple AirPlay 2, Samsung Workspace RDP ve Google Cast).
